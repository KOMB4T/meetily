# SA Meeting Protocol

## Что добавлено

В форк добавлен новый встроенный профиль summary:

- Name: `SA Meeting Protocol`
- ID: `sa_meeting_protocol`

Профиль формирует структурированный Markdown-протокол встречи на русском языке для рабочих встреч системного аналитика.

Дополнительно для этого профиля включены отдельные chunk/combine prompts, чтобы промежуточные summary тоже целенаправленно извлекали:

- договорённости;
- дальнейшие действия;
- решения;
- требования и изменения;
- открытые вопросы;
- риски и спорные моменты;
- места для ручной проверки.

## Где находится профиль

- JSON шаблон: `frontend/src-tauri/templates/sa_meeting_protocol.json`
- Регистрация built-in профиля: `frontend/src-tauri/src/summary/templates/defaults.rs`
- Final prompt override, chunk/combine prompts и точный Markdown-каркас обрабатываются в:
  `frontend/src-tauri/src/summary/processor.rs`

## Как выбрать профиль в UI

1. Открыть страницу встречи.
2. В блоке summary нажать `Template`.
3. Выбрать `SA Meeting Protocol`.
4. Нажать `Generate Summary` или `Regenerate Summary`.

Выбор профиля сохраняется в `localStorage` браузерного слоя приложения и подставляется повторно, если профиль по-прежнему доступен.

## Какие настройки LLM использовать

Для локального OpenAI-compatible endpoint:

- Provider: `custom-openai`
- Base URL: `http://127.0.0.1:8080/v1`
- API Key: `local-dev-key`
- Model: `qwen3-14b-local`

Профиль не хардкодит endpoint и не меняет provider/model. Используются существующие настройки Meetily.

## Известные ограничения

- Запись встречи, Whisper pipeline и provider settings не менялись.
- Профиль рассчитан на Markdown-результат и не добавляет отдельный UI-редактор prompt.
- Локальный endpoint должен быть доступен отдельно; профиль сам его не поднимает.

## Проверка применения профиля

Проверка кода показала:

- изначально `SA Meeting Protocol` влиял только на final summary prompt;
- chunk stage и combine stage использовали общий prompt, одинаковый для всех шаблонов.

После доработки:

- `template_id = sa_meeting_protocol` использует отдельный chunk prompt;
- `template_id = sa_meeting_protocol` использует отдельный combine prompt;
- поведение остальных шаблонов не меняется.
